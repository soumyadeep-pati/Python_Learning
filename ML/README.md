# Machine Learning

This repository combines **Machine Learning theory, mathematics, Python programming, algorithms from scratch, practical implementations, experiments, and projects**.

The goal is to understand not only how to use Machine Learning libraries, but also **how and why the algorithms work mathematically and computationally**.

---

## Course Information

- **Course:** Machine Learning
- **Language:** Python
- **Primary Environment:** Jupyter Notebook

The repository follows the six major units specified in the university syllabus.
